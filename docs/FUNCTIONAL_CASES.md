# 双语写作模块 · 完整功能用例与操作手册

> 覆盖本次新增的全部功能。每条用例包含前置条件、操作步骤与预期结果，可直接作为人工验收清单，也是演示视频的脚本蓝本。
> 启动：`PORT=3200 URL=http://localhost:3200 corepack yarn dev:watch`，浏览器打开 `http://localhost:3200`。语法校对依赖 LanguageTool（`LANGUAGETOOL_URL`），翻译默认走免费服务商（无需 API Key）。
> 分支 `feat/bilingual-editor`（已合入本地 main）。

## 模块 A · 双语分屏写作

### A1. 从侧边栏进入双语工作台

| | |
| --- | --- |
| 前置 | 已登录工作区，侧边栏可见 |
| 步骤 | 1. 观察左侧边栏底部区域 2. 点击「Bilingual writing」 |
| 预期 | 进入「Bilingual documents」列表页；页面提供「New bilingual document」按钮；空列表显示占位文案 |

### A2. 新建双语文档（同名两份）

| | |
| --- | --- |
| 前置 | 在 Bilingual documents 列表页 |
| 步骤 | 1. 点击「New bilingual document」 2. 等待跳转 |
| 预期 | 自动创建同名两份文档（英文源 + 中文镜像，中文副本 `language=zh`）并进入分屏编辑器；左侧标题栏显示源文档，右侧标题只读并随左侧同步；侧边栏/集合中可见两篇同名文档 |

### A3. 对已有文档开启双语

| | |
| --- | --- |
| 前置 | 打开任意一篇自己可编辑的英文文档 |
| 步骤 | 1. 点击右上角「Document options」（⋮） 2. 菜单中点击「Bilingual editor」 |
| 预期 | 创建中文镜像文档并跳转至 `/doc/<slug>/bilingual` 分屏；若文档已属于某个双语对则直接打开既有分屏 |

### A4. 左侧写作 → 结构自动镜像

| | |
| --- | --- |
| 前置 | 处于分屏编辑器，左侧为空或已有内容 |
| 步骤 | 1. 在左侧输入一个段落，回车，再输入一段 2. 观察右侧 |
| 预期 | 右侧自动出现与左侧相同数量的空段落（约 250ms 内完成结构镜像）；删除左侧某段，右侧对应段落同步删除；顶层结构始终保持一一对应 |

### A5. 自动翻译写入右侧

| | |
| --- | --- |
| 前置 | 左侧已输入英文段落 |
| 步骤 | 1. 停止输入约 2–8 秒（1.5s 防抖 + 翻译请求） |
| 预期 | 右侧对应段落自动出现中文译文；块状态标记为「auto」；多段内容会分批（每批 ≤20 段）依次写入 |

### A6. 人工修改保护（防覆盖）

| | |
| --- | --- |
| 前置 | 右侧某段已有自动译文 |
| 步骤 | 1. 在右侧该段落手动改写任意文字 2. 回到左侧再修改对应英文段落 |
| 预期 | 右侧人工内容**不会被覆盖**；该块状态变为「stale/manual」并在 UI 上有提示；通过「重新翻译」强制覆盖后才恢复 auto |

### A7. 结构不一致告警与一键修复

| | |
| --- | --- |
| 前置 | 人为造成两侧块数不一致（如直接在右侧增删段落） |
| 步骤 | 1. 观察分屏顶部 2. 点击「Repair」 |
| 预期 | 顶部出现「Structure out of sync」黄色告警条；点击 Repair 后右侧结构按左侧重建，告警消失 |

### A8. 级联删除（两份一起删）

| | |
| --- | --- |
| 前置 | 打开双语对的源文档菜单 |
| 步骤 | 1. Document options → Delete 2. 确认删除 |
| 预期 | 英文源与中文镜像**同时**进入垃圾箱，双语对记录一并删除；不会残留孤儿中文文档 |

### A9. 双语列表与重新对齐

| | |
| --- | --- |
| 前置 | 已存在至少一个双语对 |
| 步骤 | 1. 侧边栏 → Bilingual writing 2. 查看列表并点击条目 |
| 预期 | 列表显示每个双语对（源标题、EN→CN 标记）；点击进入对应分屏；服务端 `bilingual.realign` 可重建块状态数组 |

## 模块 B · 划词翻译

### B1. 选中句子 → 右下角圆点 → 翻译卡片

| | |
| --- | --- |
| 前置 | 打开任意英文文档（普通模式或双语分屏左侧） |
| 步骤 | 1. 用鼠标选中一个句子 2. 等待约 250ms 3. 观察选区末行**右下方**出现的 8px 圆点 4. 点击圆点 |
| 预期 | 弹出翻译卡片：顶部为「Source · Detected English」与服务商下拉（Automatic / Microsoft (free)…）；中部原文回显；下方为中文译文；底部有 Copy（复制）、Speak（朗读）按钮 |

### B2. 选中单词 → 直接弹出词义卡（含句子语法）

| | |
| --- | --- |
| 前置 | 文档中有英文句子，如 `The value is 3.14 meters.` |
| 步骤 | 1. 双击选中一个英文单词（或悬停模式开启时悬停） |
| 预期 | **无需点击**，直接弹出卡片：显示单词的中文释义 + 「Grammar in this sentence」区域列出该单词所在句子的语法问题（类型徽章 + 说明）；同样具备 Copy/Speak |

### B3. 「写入中文段」联动

| | |
| --- | --- |
| 前置 | 在双语分屏的左侧选中一段文字并打开翻译卡片 |
| 步骤 | 1. 点击卡片上的「Write into mirror」 |
| 预期 | 译文立即写入右侧对应段落；该块状态更新为 auto；不受防覆盖保护限制（用户显式操作） |

### B4. 卡片交互细节

| | |
| --- | --- |
| 步骤 | 1. 打开翻译卡片 2. 分别测试：切换服务商下拉、Copy、Speak、Esc、点击卡片外部、拖动窗口滚动页面 |
| 预期 | 服务商下拉立即重新翻译；Copy 写入剪贴板；Speak 朗读译文；Esc 与外部点击关闭卡片；页面滚动时圆点/卡片自动隐藏（防止指错位置） |

### B4.5 单词词典卡的三级查词

| | |
| --- | --- |
| 前置 | 双击选中一个英文单词 |
| 步骤 | 1. 观察卡片来源徽标 2. 分别测试无 AI Key / 配置 AI 服务两种场景 |
| 预期 | 查词按三级解析：**本地 ECDICT 词典**（无需任何 API Key，含音标/义项/例句，来源 ecdict）→ 团队配置的 **AI 词典**（来源 ai）→ **机器翻译兜底**（来源 mt-fallback）；结果 Redis 缓存 |

### B5. 翻译服务端能力

| | |
| --- | --- |
| 步骤 | 1. 连续发起多次翻译 2. 相同文本再次翻译 3. （可选）配置 `OPENAI_API_KEY`/`DEEPL_API_KEY` 后重启 |
| 预期 | 免费服务商失败自动降级到链上下一个（`TRANSLATION_PROVIDER_ORDER`）；相同文本命中 Redis 缓存（秒回）；所有 API Key 只存在于服务端，接口不回显 |

## 模块 C · 语法校对

### C1. 实时下划线（五类四色）

| | |
| --- | --- |
| 前置 | 打开英文文档（编辑中） |
| 步骤 | 1. 输入含错的句子，如 `She dont know wether he recieved there package. We discussed about it, and made a big progress yesterday.` 2. 停顿约 1 秒 |
| 预期 | 出现波浪下划线：拼写红、语法橙、标点蓝、风格紫（点线）、其他灰；与 LanguageTool 网页工作台的分类一致 |

### C2. 句下问题圆点（行内尾随）

| | |
| --- | --- |
| 步骤 | 1. 同 C1 输入 2. 观察每段末尾 |
| 预期 | 句子问题以彩色小圆点**紧随段落最后一个字符之后**（在同一文本行内），不再悬空在段落之间；悬停圆点显示提示文案 |

### C3. 点击下划线 → 问题卡

| | |
| --- | --- |
| 步骤 | 1. 点击任意一个波浪下划线 |
| 预期 | 弹出问题卡：类别色徽章（如 Typo/Spelling）+ 说明 + **规则 ID**（如 `MORFOLOGIK_RULE_EN_US`，等宽字体）+ 高亮上下文 + 替换按钮（蓝色）+「Ignore this rule」 |

### C4. 句下圆点 → 问题卡

| | |
| --- | --- |
| 步骤 | 1. 点击段落末尾的彩色小圆点 |
| 预期 | 打开该问题的详情卡（与 C3 相同的卡片） |

### C5. 一键修复与撤销

| | |
| --- | --- |
| 前置 | 问题卡已打开（含替换按钮，如 Hellow → Hello） |
| 步骤 | 1. 点击某个替换按钮 2. `Ctrl/Cmd+Z` |
| 预期 | 修复以普通事务应用，文本立即替换并重新校对；撤销可完整还原 |

### C6. 忽略规则

| | |
| --- | --- |
| 步骤 | 1. 问题卡点击「Ignore this rule」 2. 观察全文 |
| 预期 | 该规则在当前用户的所有同类问题立即消失（下划线+圆点），并持久保存（localStorage）；重新加载后仍生效 |

### C7. Picky 模式

| | |
| --- | --- |
| 步骤 | 1. 工作区设置把 `grammarLevel` 切到 `picky`（或调用 `setGrammarLevel`） 2. 输入含风格问题的句子 |
| 预期 | 更严格的规则（风格/标点细节）被激活，出现紫色风格下划线 |

### C8. 服务降级

| | |
| --- | --- |
| 步骤 | 1. 停掉 LanguageTool 容器 2. 输入文本 3. 重新启动容器 |
| 预期 | 校对静默降级（无报错弹窗、不影响输入），界面不出现新下划线；服务恢复后自动恢复校对（熔断器半开重试） |

## 已知边界（v1）

- 列表、表格、代码块等非段落块：结构上保持一一对应的空占位（状态 `skipped`），内容不自动翻译；自动对齐只针对空白镜像，已有内容走「Repair」。
- 中文全文搜索受 PostgreSQL `english` 分词配置限制（历史问题，非本模块引入）。
- 翻译弹层/问题卡使用基础亮暗主题（不继承自定义工作区主题）。
- MCP 工具与集合级删除暂不触发配对级联（垃圾箱永久删除时数据库级联自愈）。

## 演示视频录制分镜（本地录屏用）

> 本环境的自动化录屏通道不可用，因此提供分镜脚本：打开 QuickTime Player →「文件 → 新建屏幕录制」，按以下镜头顺序操作即可录出约 3 分钟的功能演示视频。每个镜头对应上文同名用例。

| 镜头 | 时长 | 页面 | 操作（配旁白要点） |
| --- | --- | --- | --- |
| 1 开场 | 5s | `http://localhost:3200/doc/new` | 展示空白文档：「这是一篇英文文档，我们边写边校对」 |
| 2 实时校对 | 15s | 同上 | 输入 `hellow every one , can you help me learn english. She dont know wether he recieved there package and made a big progress yesterday.`（用例 C1）；停顿 2 秒展示红/橙/蓝下划线与句末彩色圆点 |
| 3 点击下划线 | 10s | 同上 | 点击 `hellow` 的红色下划线（用例 C3）：展示问题卡——类别徽章、规则 ID、上下文、替换按钮 |
| 4 一键修复 | 8s | 同上 | 点击蓝色替换按钮 `Hello`（用例 C5），强调「Ctrl+Z 可撤销」；再点句下圆点打开第二张卡（C4） |
| 5 划词翻译 | 15s | 同上 | 用鼠标拖选整个句子 → 右下角出现蓝色小圆点 → 点击（用例 B1）：展示翻译卡、服务商下拉、复制/朗读 |
| 6 单词直弹卡 | 12s | 同上 | 双击选中一个英文单词（用例 B2）：卡片直接弹出，含释义与「Grammar in this sentence」语法区 |
| 7 开启双语 | 10s | 同上 | 点右上 ⋮ → 「Bilingual editor」（用例 A3）：进入左右分屏，右侧出现同名中文文档 |
| 8 结构镜像+自动翻译 | 20s | 分屏 | 左侧输入/修改一段英文（用例 A4/A5）：右侧结构同步、中文译文自动写入；把光标放到右侧改一个词（用例 A6）展示防覆盖提示 |
| 9 同名两份与入口 | 10s | 侧边栏 | 展示集合中两篇同名文档、侧边栏「Bilingual writing」入口与列表页（用例 A1/A9/D2） |
| 10 收尾 | 5s | 分屏 | 展示「Structure out of sync / Repair」能力（先在右侧手动加一段触发告警，点击 Repair 一键修复，用例 A7） |

> 录制完成后导出为 `bilingual-demo.mp4` 即可与本文档一起分发给团队成员。
